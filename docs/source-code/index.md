# Source Code

**Quantum Computing for Scientific Computing (QCLS)**
project is publicly available on GitHub.

## Variational Quantum Linear Solver (VQLS)

Implementation of the Variational Quantum Linear Solver
for investigating quantum approaches to solving
linear systems.

## VLQ-EU Hardware Experiments and Tutorials

This repository documents the Qiskit → QaaS → IT4Innovations
VLQ workflow, including LEXIS access, quantum backend
initialization, execution, and analysis of five small
quantum circuits.

It also provides educational tutorials and presentation
materials for learning and experimenting with quantum
computing on VLQ-EU hardware.

**The tutorials and educational materials are continuously updated.**
